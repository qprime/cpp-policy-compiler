# CLAUDE.md

Artifact: `CLAUDE.md` at the repository root. Unconditional — every project has one.

## Sections

Write the sections in this order. Omit an optional section when it does not apply.
Do not omit, reorder, or add anything else.

### Header

Project name and a short description for context.

### Expertise

Table the areas of expertise this project needs (e.g. C++, technical writing, PLC
design, CAD/CAM).

### Look-Up Map

Where things live, as a table. Give document breadcrumbs rather than a code map:
`README.md`, `INVARIANTS.md`, `GLOSSARY.md`, `ONTOLOGY.md`, the conventions file
governing each language, where specs go. Early in a project some of these do not
exist yet. Leave a breadcrumb blank until its document exists.

Give each row the document, its location, its role, and when to use it.

### Capabilities

A table of named behaviors this project offers. Give each row a named behavior and
a description.

### Skill Routing *(optional)*

A "user says X → use command Y" table. The table is the whole section.

Add a row when you add a command.
