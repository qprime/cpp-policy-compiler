# GLOSSARY.md

Artifact: `GLOSSARY.md` at the repository root. Earned when the project has
vocabulary whose misreading would produce wrong work.

## Sections

Write the sections in this order. Omit an optional section when it does not apply.
Do not omit, reorder, or add anything else.

### Header

Project name and a short description for context.

### Terms

The project's vocabulary, as a table. Give each term one row, sort alphabetically,
and use two columns. Add a term when misreading it would produce wrong work.

Give each row the term and its meaning in one or two sentences. Where a term names
something documented elsewhere, define it in one line and link that home rather
than summarizing it.
