# Source

Material policies are derived from. Nothing here is guidance — it is the
evidence guidance cites.

Two natures:

- **External material** — captured copies of things that exist elsewhere:
  YouTube transcripts (the `fetch-yt-transcripts` skill captures these), web
  documents, local documents. Web sources rot and videos vanish, so the
  captured copy is what attribution points at.
- **Original testimony** — experienced opinion recorded here first. This repo
  is the source of record; provenance is who said it and when.

No fixed layout yet — the first captures shape it. If a local document is
purchased material, it constrains whether this folder can ever be shared;
flag it when adding.
